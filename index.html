Calculation

IQ, height, and face are converted using their respective Z-score percentile tables.

The tables define the relationship between each raw measurement, percentile, and standard deviation from the mean.

Population: Worldwide males aged 18–30.

Z-score limits: −3 ≤ Z ≤ 4

IQ: SIQ = sign(Z) × |Z|1.5

Height:
Z ≥ 0: SH = 0.72 × Z1.14
Z < 0: SH = −1.45 × |Z|0.95

Face: SF = sign(Z) × |Z|1.64

Overall: S = (SIQ + SH + SF) / 3

The final S score is transformed into the 0–8 Predisposition Index.

Population percentile: The displayed PI population percentile is an estimated percentile based on the supplied PI-to-population-percentile reference table. Values between table points are interpolated.
