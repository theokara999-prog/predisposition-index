Calculation

IQ, height, and face are converted using their respective Z-score percentile tables.

The tables define the relationship between each raw measurement, percentile, and standard deviation from the mean.

Population: Worldwide males aged 18–30.

Z-score limits: −5 ≤ Z ≤ 5

IQ: SIQ = sign(Z) × |Z|1.5

Height:
Z ≥ 0: SH = 0.72 × Z1.14
Z < 0: SH = −1.45 × |Z|0.95

Face: SF = sign(Z) × |Z|1.64

Overall: S = (SIQ + SH + SF) / 3

PI transformation:
For −10.63 ≤ S < 0:
PI = 4 − 4 × (1 − e−0.2077|S|) / (1 − e−0.2077(10.63))

For 0 ≤ S ≤ 9.9:
PI = 4 + 4 × (1 − e−0.3668S) / (1 − e−0.3668(9.9))

S range: −10.63 ≤ S ≤ 9.90

PI range: 0 ≤ PI ≤ 8

Population percentile: The displayed population percentile is interpolated from the S Overall reference table.

Population rarity: The displayed "1 in N" value is interpolated logarithmically from the Rating Scale rarity values.
